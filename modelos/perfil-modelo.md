# Modelo de perfil

Copie este arquivo para a pasta dados/ (ex.: dados/perfil.md) e troque tudo
pelos seus dados reais. A pasta dados/ não vai para o Git.

Regras que fazem a busca funcionar bem:
- Um título (#, ##) por assunto. Cada título vira um trecho separado no banco.
- Um projeto inteiro debaixo do mesmo título: o que fez, com quais tecnologias, qual o resultado.
- Escreva frases completas. "Python" solto ajuda pouco; "usei Python para automatizar relatórios" ajuda muito.
- Só escreva o que é verdade. O agente vai usar isto como prova do que você sabe.

## Formação
Curso, instituição, semestre atual e previsão de formatura.

## Projeto: <nome do projeto>
O que é, qual problema resolve. O que EU fiz nele. Tecnologias usadas.
Resultado (números se tiver: usuários, tempo economizado, nota).

## Projeto: <outro projeto>
...

## Experiência: <empresa ou atividade>
Período, função, o que fazia no dia a dia, ferramentas.

## Certificados e cursos
Nome, instituição, ano, o que aprendeu.

## Idiomas
Idioma e nível real (ex.: inglês intermediário, leio documentação sem dificuldade).

## Preferências de vaga
Tipo de trabalho (presencial, híbrido, remoto), cidade, carga horária.
Tecnologias que quero usar. Tecnologias ou áreas que quero evitar.
